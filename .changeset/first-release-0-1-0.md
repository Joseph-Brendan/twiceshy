First release of Twiceshy 0.1.0.

- **twiceshy**: the repeat-action guard library. Wrap a refund, transfer, message, or booking function and duplicate retries stop at the door.
- **@twiceshy/mcp-proxy**: the same protection for existing MCP servers, added by changing one line of client config.

Both packages ship with the full documentation: choosing key fields, what in doubt means, window versus retention, limits, and the error reference.
